# Фронтенд страницы «Крафт» — правила

Страница `craft.html` построена на Preact + htm без сборки (`public/vendor/*`), стили — `public/css/next.css`. Любая правка интерфейса следует этим правилам, чтобы страница не превратилась обратно в нагромождение.

## Архитектура
- **Логика отдельно от интерфейса.** Расчёты — чистые функции в `logic/*.js` (без DOM, с юнит-тестами в `tests/next*.test.js`): `acquire` (план закупки), `profit`, `manual` (свои цены, план продажи), `cityPrices`, `factionPlan`, `stack`. Компонент только показывает и передаёт правки.
- **Состояние — в хранилищах** (`createStore` из `lib.js`): `settings` (параметры), `list` (крафт-лист), `nav`, `calc-store`, `scan`, `faction`, `lazy`. Компоненты подписываются через `useStore`. Никаких глобальных переменных и ручного DOM.
- **Один компонент — одна задача.** Повторяющиеся куски выносятся в общий компонент (`ui.js`: метки предмета, города, переключатели; `citylist.js`: панель «Все города»), а не копируются в разные вкладки.
- **Стеки позиций.** Крафт-лист и стек калькулятора — один и тот же объект (`list.js` → `createStack`, расчёт — `listcalc.js` → `createStackEngine`, общие компоненты — `stack-ui.js`). Новая функциональность стека пишется один раз для обоих. Стек калькулятора — копия активных позиций листа (`stack-open.js`), правки в нём лист не меняют.
- **Свои цены материалов** — общее хранилище `prices.js` (единая цена, цены городов, лог лотов) для калькулятора, листа и стека; применяются через `logic/adjust.js`.
- **Вкладки инструментов:** `scan.js`, `calc*.js`, `faction.js`, `lazy.js`; общий каркас — `app.js`; крафт-лист — `dock.js` + `listcalc.js`.
- **Запросы** — только через `apiGet/apiPost` (`lib.js`); общие параметры расчётов — `commonParams()` из `settings.js`. Бэкенд без необходимости не трогаем.

## Дизайн
- Цвета, отступы, радиусы — только переменные из `:root` в `next.css`; своих цветов в компонентах нет. Хорошее — `--good`, плохое — `--bad` (мягкие), акцент один — `--accent`.
- Тир, зачарование, качество — компонент `Tags`; город — `CityPill`; значок предмета — `Glyph`. Цифры — с `fmt`/`signed`, знак и цвет вместе.
- Принцип «сначала главное»: вердикт/итог сверху, детали — во вкладках и раскрывающихся панелях (`details`), редкие настройки — в «Ещё». Серые поля «своя цена» не расставляются по таблице, а прячутся в раскрывающиеся панели.
- Поле ввода со своим значением: серым — рыночное (placeholder), рамка акцентом — когда вписано своё.
- Новый элемент должен работать на телефоне, в тёмной и светлой теме и с клавиатуры (`aria-*`, подписи).

## Тесты
- Каждая новая логика — юнит-тест; каждый пользовательский сценарий — e2e в `e2e/craft-next.spec.js` (десктоп и телефон).
- Прежняя страница — `craft-classic.html` (временно), её код и тесты не расширяем.
